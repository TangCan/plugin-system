## Findings

### Architecture delta

- **观察：** `dynamic_native` 从 `ManuallyDrop<Library>` 改为 `Mutex<Option<Library>>`；`destroy_instance` 在 `vtable.destroy` 之后 `take` 并 Drop `Library`。默认 features 仍不依赖 `libloading`。WASM 路径不在本范围文件列表中。
  - **来源：** `crates/plugctx/src/dynamic_native.rs` L42–L117；`b628dd9`；`cargo tree -p plugctx -i libloading` 默认失败、`--features dynamic-native` 才出现 `libloading v0.8.9`
  - **处置：** accept as-is（符合 AD-1）
  - **课：** 无

### Duplication map

- **观察：** 未新增 `reload()`；换路径与同路径覆盖都走既有 `load_native_plugin` + dispose + load。测试名含 `reload_*` 但是函数，不是公共 API。
  - **来源：** 仓库 `pub fn reload` 无匹配；`crates/plugctx/tests/acceptance_story_4_2.rs` `reload_different_path_hello_then_echo` / `reload_same_path_after_replacing_artifact`
  - **处置：** accept as-is（AD-3）
  - **课：** 无

### God-class / size growth
