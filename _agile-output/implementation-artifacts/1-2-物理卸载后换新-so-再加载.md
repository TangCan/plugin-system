# Story 1.2: 物理卸载后换新 .so 再加载

Status: done

## Story

As a 插件作者,
I want 卸掉旧 native 库之后再加载新的动态库,
so that 进程不必重启就能换上新行为。

## Acceptance Criteria

1. **Given** 已按 1.1 物理卸载某个 native 插件  
   **When** 用 `load_native_plugin` 加载另一路径 cdylib（hello → echo），再 `Context::plugin`  
   **Then** 新插件 `call` 为 echo 行为；旧 invoker 失败

2. **Given** 已物理卸载  
   **When** 同一临时路径覆盖为另一制品后再 `load`  
   **Then** 新实例行为来自新制品

3. ABI mismatch 仍返回 `Error::AbiMismatch`（既有测试）

4. 默认同步 Context；不新增 `reload()`；失败可 `match` Error

## Tasks / Subtasks

- [x] 另一路径热替换（AC: #1）
- [x] 同路径覆盖制品（AC: #2），`#[cfg(not(windows))]`
- [x] ABI 门闩保持（AC: #3）
- [x] 默认同步、无 `reload()`（AC: #4）
